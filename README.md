SkillCraft Technology --- Task 01: Sales Dashboard
Project Overview
This project was completed as Task 01 during my internship at
SkillCraft Technology. It focuses on analyzing sales data and
presenting key findings in an Excel dashboard.
Objectives
- Summarize sales performance.
- Compare sales across product categories.
- Visualize sales trends over time.
- Use PivotTables, PivotCharts, and conditional formatting to make the
  data easier to interpret.
Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel slicers
- Conditional formatting
Dashboard Features
- Total Sales KPI
- Total Orders KPI
- Total Customers KPI
- Sales by Category chart
- Monthly Sales Trend chart
- Interactive slicers for filtering the dashboard
Data Note
The dataset supplied for this task did not include Profit or
Discount columns. Therefore, actual profit-by-category and discount
analysis could not be calculated from the available data. No values were
fabricated.

How to View
1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel to explore the dashboard, charts,
   PivotTables, and slicers.
3. View Task1_Dashboard.png for a quick visual preview, if included.
