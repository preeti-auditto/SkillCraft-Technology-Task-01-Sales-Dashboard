# Excel Sales Dashboard — Task 1

## Project Overview
This project presents a sales dashboard created using Microsoft Excel for an internship task.

## Objectives
- Analyze total sales.
- Compare sales across product categories.
- Visualize monthly sales trends.
- Use PivotTables, PivotCharts, and conditional formatting.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel slicers
- Conditional formatting

## Dashboard Features
- Total Sales KPI
- Total Orders KPI
- Total Customers KPI
- Sales by Category chart
- Monthly Sales Trend chart
- Interactive filters for year, date, and category

## Data Limitation
The supplied dataset did not include a Profit column, so profit by category could not be calculated from the available data.
